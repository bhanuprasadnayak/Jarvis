# Jarvis 🤖

A Python-based voice assistant inspired by JARVIS.  
Jarvis listens for the wake word **"Jarvis"**, understands voice commands, performs useful actions, and can respond using an AI model.

## ✨ Features

- 🎙️ Voice recognition using SpeechRecognition
- 🔊 Text-to-speech responses using gTTS and Pygame
- 🤖 AI-powered responses using Groq and Llama 3.3
- 🌐 Open websites using voice commands
- 🎵 Play songs through YouTube
- 📰 Fetch and read the latest news headlines
- 🗣️ Wake-word activation using "Jarvis"
- ⚡ Simple and lightweight command-based architecture

## 🛠️ Technologies Used

- Python
- SpeechRecognition
- Google Text-to-Speech (gTTS)
- Pygame
- Groq API
- Llama 3.3 70B
- NewsAPI
- Requests
- Webbrowser
